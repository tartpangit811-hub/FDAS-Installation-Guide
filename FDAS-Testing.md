# FDAS Testing and Commissioning

## Purpose of Testing

Testing is performed to ensure that all FDAS devices, wiring, and control panel functions are operating properly before system handover.

## 1. Visual Inspection

Check the physical condition of the installed system.

- Verify device installation locations
- Check cable labels
- Inspect wiring connections
- Confirm proper mounting of devices
- Check panel condition

## 2. Device Testing

Test each FDAS device to confirm proper operation.

- Test smoke detectors
- Test heat detectors
- Test manual call points (MCP)
- Test sounders and alarm bells
- Test strobe lights

## 3. Fire Alarm Control Panel Testing

Check the operation of the Fire Alarm Control Panel (FACP).

- Verify normal standby condition
- Check alarm activation
- Check fault indicators
- Confirm zone/device identification
- Review alarm history

## 4. Battery and Power Testing

- Check main power supply
- Test backup battery operation
- Verify battery voltage
- Confirm system operation during power failure

## 5. Documentation and Handover

After testing is completed:

- Record test results
- Prepare inspection reports
- Document system issues and corrections
- Provide client orientation
- Complete system handover
