# FDAS Troubleshooting Guide

## Common FDAS Problems and Solutions

## 1. Fire Alarm Panel Shows Fault

### Possible Causes:
- Open circuit in wiring
- Short circuit on cable
- Loose cable connection
- Device communication problem

### Solutions:
- Check field wiring
- Inspect cable termination
- Test cable continuity
- Check device connections

---

## 2. Smoke Detector Not Responding

### Possible Causes:
- Incorrect wiring
- Dirty detector chamber
- Faulty detector
- Wrong device address

### Solutions:
- Check detector wiring
- Clean or replace detector
- Verify device address
- Test using proper tools

---

## 3. False Alarm Activation

### Possible Causes:
- Dust or contamination
- Environmental factors
- Damaged detector
- Incorrect detector location

### Solutions:
- Clean detector
- Check installation location
- Replace defective devices
- Review system settings

---

## 4. Alarm Sounder or Strobe Not Working

### Possible Causes:
- Wiring problem
- Power supply issue
- Faulty alarm device

### Solutions:
- Check voltage supply
- Inspect connections
- Replace defective devices

---

## 5. Preventive Maintenance

To avoid FDAS problems:

- Perform regular testing
- Inspect cables and connections
- Clean detectors
- Check backup batteries
- Review alarm history
- Keep system records updated
