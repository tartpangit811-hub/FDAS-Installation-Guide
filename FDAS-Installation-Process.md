# FDAS Installation Process

## Step 1: Site Survey and Planning

Before installation, perform a complete site survey and planning.

- Review FDAS drawings and system layout
- Identify detector and device locations
- Check cable routes and pathways
- Identify possible fire hazards
- Verify installation requirements and standards

## Step 2: Cable Installation

Proper cable installation is important for reliable FDAS operation.

- Use approved fire alarm cables
- Follow proper cable routing methods
- Maintain proper cable separation
- Label both cable ends
- Perform continuity testing

## Step 3: Device Installation

Install all FDAS devices according to the approved layout.

- Install smoke detectors
- Install heat detectors
- Install manual call points (MCP)
- Install sounders and alarm bells
- Install strobe lights
- Connect devices to the Fire Alarm Control Panel (FACP)

## Step 4: Panel Installation and Termination

- Mount the Fire Alarm Control Panel securely
- Connect incoming power supply
- Terminate field cables properly
- Check wiring connections
- Install backup batteries

## Step 5: Testing and Commissioning

Perform complete system testing before handover.

- Test all detection devices
- Check alarm signals
- Verify sounder and strobe operation
- Check fault monitoring
- Test backup battery operation
- Record test results

## Step 6: Final Inspection and Handover

- Perform final system inspection
- Correct installation issues
- Prepare documentation
- Provide system orientation to the client
